8.7. Agent Evaluation and Safety#

8.7.1. Learning objectives#

By the end of this section, you should be able to:

  • Apply a structured evaluation rubric to agent outputs along four dimensions: goal completion, reasoning quality, tool efficiency, and answer accuracy.

  • Identify the five most common agent failure modes and explain what causes each.

  • Implement input sanitization to prevent prompt injection attacks.

  • Implement output content filtering to block harmful or policy-violating responses.

  • Configure step limits and error budgets to prevent runaway agent loops.

8.7.2. Why Agent Evaluation Is Hard#

Evaluating a single LLM response is straightforward: does the output answer the question correctly? Evaluating an agent is harder because the agent produces:

  1. A reasoning trace — a sequence of thoughts and tool calls (is the reasoning correct at each step?)

  2. Tool use — a sequence of tool invocations (are the right tools used efficiently?)

  3. A final answer — the ultimate response (is it correct and well-grounded?)

Failure can occur at any of these three levels. A correct final answer can be produced by incorrect reasoning. A correct reasoning trace can lead to a wrong answer due to a tool error. Traditional accuracy metrics capture only level 3.

8.7.3. The Evaluation Rubric#

A structured evaluation rubric makes agent assessment reproducible:

def evaluate_agent_output(
    goal: str,
    agent_trace: list[dict],  # list of {thought, action, observation} dicts
    final_answer: str,
    ground_truth: str = None,
) -> dict:
    """
    Evaluate an agent run across four dimensions.
    Returns a dict with scores (1–5) and explanations.
    """
    return {
        "goal_completion": {
            "score": None,  # 1–5: did the agent address all aspects of the goal?
            "criteria": [
                "5 — All aspects of the goal are addressed",
                "3 — Most aspects addressed; one omission",
                "1 — Goal not addressed or completely misunderstood",
            ],
        },
        "reasoning_quality": {
            "score": None,  # 1–5: are each Thought steps logical?
            "criteria": [
                "5 — Every Thought is logically justified",
                "3 — Mostly logical with one questionable step",
                "1 — Reasoning is circular, irrelevant, or missing",
            ],
        },
        "tool_efficiency": {
            "score": None,  # 1–5: did the agent use tools appropriately?
            "criteria": [
                "5 — Minimum necessary tools; no redundant calls",
                "3 — One unnecessary tool call",
                "1 — Repeated calls, wrong tools, or tools ignored when needed",
            ],
        },
        "answer_accuracy": {
            "score": None,  # 1–5: is the final answer factually correct?
            "criteria": [
                "5 — Correct and well-grounded in observations",
                "3 — Mostly correct; minor inaccuracy",
                "1 — Incorrect or contradicts the observations",
            ],
        },
    }

def llm_judge_agent(goal: str, trace_str: str, final_answer: str, judge_llm) -> str:
    """Use an LLM to evaluate agent performance."""
    judge_prompt = f"""<|user|>
You are an expert AI evaluator. Evaluate the following agent run on a scale of 1–5
for each dimension.

Original goal: {goal}

Agent reasoning trace:
{trace_str}

Final answer: {final_answer}

Rate each dimension (1=poor, 5=excellent) with a one-sentence justification:
- Goal completion: Did the agent address all aspects of the goal?
- Reasoning quality: Was each Thought step logical and relevant?
- Tool efficiency: Were tools used appropriately without unnecessary calls?
- Answer accuracy: Is the final answer correct and well-grounded?
<|end|>
<|assistant|>
"""
    return judge_llm.invoke(judge_prompt).strip()

8.7.5. Implementing Safety Guardrails#

8.7.5.1. 1. Input Sanitization#

Prevent users from injecting instructions that override the agent’s behavior:

Show code cell source

Hide code cell source

 
import re

INJECTION_PATTERNS = [
    r"ignore\s+(previous|all|above)\s+instructions",
    r"forget\s+(everything|all)\s+you",
    r"act\s+as\s+(if\s+you\s+are\s+)?a\s+different",
    r"you\s+are\s+now\s+in\s+developer\s+mode",
    r"bypass\s+your\s+(guidelines|safety|restrictions)",
    r"pretend\s+you\s+(have\s+no|don'?t\s+have)\s+restrictions",
]

def sanitize_input(user_input: str) -> tuple[str, bool]:
    """
    Check for prompt injection patterns.
    Returns (sanitized_input, is_suspicious).
    """
    is_suspicious = any(
        re.search(pattern, user_input, re.IGNORECASE)
        for pattern in INJECTION_PATTERNS
    )

    # Strip excessive whitespace and control characters
    sanitized = re.sub(r"\s+", " ", user_input).strip()
    sanitized = re.sub(r"[^\x20-\x7E\n\t]", "", sanitized)  # ASCII printable only

    return sanitized, is_suspicious

8.7.5.2. 2. Output Content Filtering#

Filter agent outputs before returning them to the user:

Show code cell source

Hide code cell source

 
BLOCKED_PATTERNS = [
    r"\b(password|api_key|secret|token)\s*[:=]\s*\S+",  # credential leakage
    r"\b(?:rm|del|drop\s+table|delete\s+from)\s",        # destructive commands
]

def filter_output(output: str) -> tuple[str, bool]:
    """
    Screen agent output for policy violations.
    Returns (output_or_replacement, is_blocked).
    """
    for pattern in BLOCKED_PATTERNS:
        if re.search(pattern, output, re.IGNORECASE):
            return (
                "I cannot provide that information due to safety policy.",
                True,
            )
    return output, False

8.7.5.3. 3. Step Limits and Error Budgets#

Show code cell source

Hide code cell source

 
class AgentSafetyConfig:
    max_steps: int = 8              # absolute step limit
    max_tool_errors: int = 3        # max tool failures before abort
    max_repeated_actions: int = 2   # max times same action+input can repeat
    timeout_seconds: float = 60.0   # wall-clock timeout

def check_safety(
    step: int,
    tool_errors: int,
    action_history: list[str],
    config: AgentSafetyConfig,
) -> tuple[bool, str]:
    """Returns (should_abort, reason)."""
    if step >= config.max_steps:
        return True, f"Step limit of {config.max_steps} reached."
    if tool_errors >= config.max_tool_errors:
        return True, f"Too many tool errors ({tool_errors})."
    if action_history.count(action_history[-1]) >= config.max_repeated_actions:
        return True, "Detected repeated action — possible infinite loop."
    return False, ""

8.7.6. Exercises and discussion#

  1. Rubric scoring exercise Run three different questions through your agent and record the full reasoning trace for each. Score each run on all four rubric dimensions. For each run where you score below 3 on any dimension, identify the specific step where the failure occurred and propose a fix.

  2. Failure mode provocation Deliberately trigger each of the five failure modes: (a) Ask the agent to use a tool that doesn’t exist; (b) Construct a question where the observation is not sufficient for an answer but the model terminates anyway; (c) Ask a question that causes the agent to repeat the same action three times. Document the exact prompt and agent response for each.

  3. Prompt injection test Construct five prompt injection attempts of varying subtlety (from obvious “ignore your instructions” to subtle instruction embedding in a search result mock). Test each against your sanitize_input function. Which patterns does it catch? Which escape detection? Add at least two more patterns to your INJECTION_PATTERNS list based on the failures.
