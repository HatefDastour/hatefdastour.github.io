8. Language Agents and Agentic AI#

With prompt engineering established in Chapter 6, we are now ready to move beyond single-turn LLM interactions and build LLM-powered applications that orchestrate multiple model calls, maintain conversational history, use external tools, and act autonomously in pursuit of multi-step goals. This chapter introduces LangChain as a framework for these applications and culminates in the design and implementation of agentic AI systems.

We begin with the foundations of LLM application development — how to integrate local models, structure prompts with reusable templates, and manage the input/output pipeline for LLM-powered code. We then build chains: pipelines that decompose complex tasks into sequential, composable steps. The middle of the chapter addresses the memory problem — LLMs are stateless by design, and we examine three strategies for injecting conversational history into the prompt context. We then move to agents: LLMs given access to tools and the autonomy to decide which tool to use and in what order. The second half of the chapter deepens this with a full treatment of agentic AI — the Perceive-Reason-Act-Observe loop, tool registries, multi-agent architectures, evaluation, and safety. The chapter closes with a focused look at running agentic systems on lightweight open-source models suitable for resource-constrained environments.

8.1. Learning objectives#

By the end of this chapter, you should be able to:

  • Load a local LLM in GGUF format using LlamaCpp and integrate it with LangChain.

  • Build reusable prompt templates that separate instructions from variable content.

  • Implement multi-step chain pipelines using the modern RunnableSequence pattern.

  • Implement three memory strategies — ConversationBufferMemory, ConversationBufferWindowMemory, and ConversationSummaryMemory — and select the appropriate one for a given use case.

  • Equip an LLM with tools (search, calculator, custom functions) and run a ReAct agent.

  • Explain the four components of an agent system: LLM backbone, tool registry, memory, and planning mechanism.

  • Implement the ReAct (Reason + Act) loop from scratch without a framework.

  • Build and run a LangChain ReAct agent with custom tools.

  • Design a multi-agent pipeline with specialized roles (planner, researcher, aggregator).

  • Evaluate agent outputs using a structured rubric and identify common failure modes.

  • Implement safety guardrails for production agent systems.

  • Run agentic workflows on lightweight models (TinyLlama, Phi-2) and analyze the quality-speed trade-off.

8.2. How this chapter fits into the course#

Chapter 6 established the techniques for communicating effectively with a single LLM. This chapter extends that to systems of LLMs that interact with each other, with external APIs, and with the world.

The connections to other chapters are:

  • Prompt engineering (Chapter 6) provides the templates, chain-of-thought triggers, and structured output techniques that agents rely on for reliable tool-calling and reasoning.

  • Retrieval-augmented generation builds directly on the tool-use and memory patterns introduced here: RAG is, architecturally, an agent with a document retrieval tool.

  • Fine-tuning can be understood as a way to encode reliable tool-use and reasoning patterns into model weights — reducing the prompt engineering burden in agentic applications.

8.3. Chapter roadmap#

This chapter is organized into thirteen sections, each paired with slides and labs in module_07_context:

  1. LLM I/O and Local Model Integration We introduce the LangChain framework, load a local LLM in GGUF format using LlamaCpp, and explain why local models are preferred for development and privacy-sensitive applications. This section connects to slide deck s701_model_io and lab l701_advanced_text_generation_techniques_and_tools.

  2. Prompt Templates We build reusable prompt templates using PromptTemplate and explain how they separate instruction structure from variable content. This section connects to s701_model_io and lab l701_advanced_text_generation_techniques_and_tools.

  3. Chains: Building Complex Workflows We implement multi-step LLM pipelines using both the legacy LLMChain pattern and the modern RunnableSequence (pipe operator) approach. We build a three-step story generation pipeline as a running example. This section connects to s702_chains and lab l701_advanced_text_generation_techniques_and_tools.

  4. Memory: Conversation History Management We address the LLM statefulness problem and implement three memory strategies: ConversationBufferMemory, ConversationBufferWindowMemory, and ConversationSummaryMemory. We compare their behavior on long conversations. This section connects to s703_memory and lab l701_advanced_text_generation_techniques_and_tools.

  5. Agents and the ReAct Framework We introduce agents as LLMs with tools and autonomy, implement the ReAct (Reason + Act) pattern, and build a LangChain agent equipped with DuckDuckGo search and a calculator. This section connects to s704_agents and lab l701_advanced_text_generation_techniques_and_tools.

  6. Introduction to Agentic AI We formalize the agent model: the Perceive-Reason-Act-Observe (PROA) loop, the four core components of an agent system, and how agents differ fundamentally from single LLM calls and fixed chains. This section connects to s705_agentic_ai and lab l702_agentic_ai_open_source_llms.

  7. Building Tools for Agents We design Python tools that an agent can call, covering tool naming conventions, docstring-driven descriptions, typed parameters, and error handling. We build a tool registry that the agent uses to discover available capabilities. This section connects to lab l702_agentic_ai_open_source_llms.

  8. Agent Memory Systems We examine the three types of agent memory — short-term working memory, episodic conversation memory, and long-term semantic memory — and implement each type with concrete examples. This section connects to lab l702_agentic_ai_open_source_llms.

  9. Building a ReAct Agent from Scratch We implement the complete ReAct loop in pure Python without any framework — prompt template, tool-call parser, and agent loop — to expose exactly what frameworks abstract away. This section connects to lab l702_agentic_ai_open_source_llms.

  10. LangChain Agent Framework We rebuild the from-scratch agent using LangChain’s create_react_agent and AgentExecutor, comparing what the framework adds over the raw implementation. This section connects to lab l702_agentic_ai_open_source_llms.

  11. Multi-Agent Pipelines We design a multi-agent architecture where a Planner agent decomposes a complex goal, Specialist agents execute sub-tasks, and an Aggregator agent synthesizes the results. This section connects to lab l702_agentic_ai_open_source_llms.

  12. Agent Evaluation and Safety We introduce a structured evaluation rubric for agent outputs (goal completion, reasoning quality, tool efficiency, answer accuracy) and implement safety guardrails including input sanitization, content filtering, and step limits. This section connects to lab l702_agentic_ai_open_source_llms.

  13. Lightweight Models for Agentic AI We run agentic workflows on TinyLlama-1.1B and Phi-2-2.7B, analyze the quality-speed trade-off, and develop prompt design principles specific to small-model agents. This section connects to lab l703_agentic_ai_lightweight_llms.

Each section includes focused Python code snippets that echo the workflows implemented in:

  • Labs: l701_advanced_text_generation_techniques_and_tools, l702_agentic_ai_open_source_llms, l703_agentic_ai_lightweight_llms.
